# Mister X – Jagd durch London

Browser-Spiel für 3–8 Spieler: Jeder spielt am eigenen Handy, PC oder iPad. Einer ist Mister X, alle anderen jagen ihn als Detektive mit Taxi, Bus und U-Bahn durch London.

**Spielen:** https://kamil631.github.io/mister-x/

- Spiel erstellen, Code oder QR-Code teilen, Figuren wählen, los.
- Die Position von Mister X wird auf seinem Gerät verschlüsselt und ist für die anderen nicht lesbar.
- Spielstände liegen in der Supabase-Tabelle `mrx_rooms` (Projekt „K&M Projekt“).
- Testmodus ohne Server (mehrere Tabs im selben Browser): `index.html?local&p=1`, `?local&p=2`, …

Eigene London-Karte (186 Stationen, mit Straßen, Parks, Bezirken und Wahrzeichen), keine Kopie des Original-Spielbretts. Hell- und Dunkelmodus (folgt dem System oder per Schalter).
